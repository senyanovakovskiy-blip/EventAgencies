EVENTAGENCIES — ОСНОВНАЯ ВЕРСИЯ

Источник этой версии — eventagencies-light, ранее доступная локально на 8781.
Выбор владельца: вертикальная фотолента с инерцией, обновлённые каталог,
профили агентств, галереи и «Мой проект». Другие варианты не подменяют её.

Закрытый хостинг: https://eventagencies-motion.racinggiant1.chatgpt.site
Админка: /admin. Доступ только владельцу через тот же аккаунт ChatGPT.
Архитектура, ограничения и команды публикации: README-HOSTING.txt.

Локальный запуск: Node.js 24+, npm run start:local либо start.ps1.
Локальные страницы: local-dist. База: private-data, вне публичной сборки.
Облачная сборка: npm run build, результат dist (Worker + D1 + assets).
Локальные базы, пароли и сессии не импортируются в облако.

Сохранены выбор команды с кейсом, до 200 примеров работ, личные заметки,
отмена удаления и помощь с подбором без выбранной команды.
Админка поддерживает уточнение брифа, ответы агентств, согласия сторон,
передачу контактов, разговор и результат. Автоматических рассылок нет.
Неизменяемый снимок принятой заявки хранится отдельно от рабочих изменений.

Исходный браузерный шаблон и его анимации сохранены. React/TypeScript
источники исходного Motion Folio не восстанавливались. В hosted-архив
не включены восемь неиспользуемых демонстрационных галерей шаблона;
их исходные файлы сохранены в репозитории.
