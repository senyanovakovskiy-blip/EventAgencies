# EventAgencies — настройки агента

Применяй эти правила только при работе с этим проектом. Подключай навыки по задаче, не загружай всё для обычной правки.

## Навыки и инструменты

- **Graphify** — для вопросов об архитектуре, связях между файлами и широкого исследования незнакомой части проекта. Для локальных правок одного файла используй обычную навигацию по коду.
- **WebsiteBench** — только если пользователь прямо просит запустить оценку агента на заданиях бенчмарка. Он оценивает восстановление сайтов агентом и не проверяет качество EventAgencies. Перед запуском нужны Docker и Harbor; не скачивай задания и не начинай прогон без такого запроса.
- **Sites** — при изменении размещённого сайта и публикации. Сохраняй текущий публичный доступ; если развёртывание ещё выполняется, продолжай отслеживать его и не запускай второе.
- **Imagegen** — для новых оригинальных изображений, если это нужно задаче. Не подменяй сгенерированными картинками реальные фотографии агентств и их проектов.
- **Computer Use** — когда задача требует видимого действия в браузере пользователя; не используй для проверок сайта, если пользователь их не просил.
- **GitHub** — для действий с исходным репозиторием и его PR, когда это относится к запросу.
- **OpenAI Docs** — для вопросов о настройках Codex, навыках и агентах.

Утилиты Graphify, WebsiteBench и uv уже установлены в `C:\Users\ADMIN\.codex\bin`. Используй их оттуда, если команды нет в `PATH`; не устанавливай копию только из-за отсутствия команды в `PATH`.

## Данные каталога

- Используй подтверждённые сведения и сохраняй ссылку на первоисточник.
- Не выдумывай агентства, клиентов, роли, фотографии, отзывы, рейтинги, бюджеты, доступность или согласие на публикацию.
- Не запускай тесты и проверки сайта, если пользователь этого не попросил. Сборка, необходимая для сохранения или публикации версии, допустима.
