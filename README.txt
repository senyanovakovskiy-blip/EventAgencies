MOTION FOLIO — ШАБЛОН САЙТА

Запуск на Windows: откройте PowerShell в этой папке и выполните
  powershell -ExecutionPolicy Bypass -File .\start.ps1
Откроется http://127.0.0.1:8780 . Нужен Node.js 24+.
Если Node.js установлен: npm run start:local (устанавливать зависимости не требуется).
npm start предназначен для проверки собранного облачного Worker;
его подготовка и зависимости описаны в README-HOSTING.txt.

ЧТО МЕНЯТЬ
content/site.json — имя, название в загрузчике, email, город, адрес сайта,
описание, язык HTML, превью ссылки, favicon и музыка.
content/about.json — текст «О себе», опыт, услуги, клиенты, соцсети,
портрет и фотографии/подписи Real Life.
content/projects.json — проекты: title, category, year, client, role,
industry, description, seoDescription, image, imageMobile и gallery.
public/custom/theme.css — акцентный цвет, фон и дополнительные стили.
public/custom/ — положите сюда собственные изображения и видео.

Пример изображения: "image": "/custom/project-cover.webp".
Пример галереи:
  {"type":"image","src":"/custom/project-01.webp","ratio":1.5}
  {"type":"video","src":"/custom/project-02.mp4",
   "poster":"/custom/project-02.webp","ratio":1.5}
ratio = ширина / высота. Для своих изображений используйте новые имена
в /custom/: оригинальные пути связаны с готовыми AVIF/WebP вариантами.
У демонстрационных элементов есть дополнительные настройки frame,
arrange и live. Для своих обычных фото используйте простой пример выше.
slug задаёт адрес /work/slug; он должен быть уникальным и латиницей.
Можно менять порядок проектов, добавлять и удалять их.

ПОСЛЕ ИЗМЕНЕНИЙ
Повторите start.ps1 либо выполните node build.mjs и обновите страницу.
Сборка проверяет JSON, уникальность адресов и наличие локальных медиа.
local-dist/ — готовые локальные страницы, пересоздаются из настроек.
Для закрытого хостинга EventAgencies используется npm run build:
dist/ содержит облачную сборку со статическими страницами и Worker.
Приём заявок требует D1 и входа через Sites; копирования статических файлов
для этой версии недостаточно. Публикация пока готовится.
Актуальная схема и порядок размещения описаны в README-HOSTING.txt.
Можно задать другой порт через переменную окружения PORT.
Часы показывают локальное время посетителя, как в оригинале.

ОСНОВА ШАБЛОНА
Сохранены анимированные часы, прокрутка проектов, переходы,
галереи, мобильное меню, Real Life, светлая/тёмная тема и музыка.
template-source/ содержит адаптированную публичную браузерную сборку
https://quynh.moe/ с точками подстановки данных. Это не исходный
React/TypeScript-проект автора: исходники компонентов недоступны.
Логику сложных эффектов следует менять с учётом этого ограничения.
Playground и специальные интерактивные блоки остаются демопримерами.
Фотографии, кейсы, шрифты и музыка оригинала оставлены как образцы;
для собственного сайта замените материалы и подписи своими.
Подключение аналитики оригинального сайта отключено.
Исходная локальная копия quynh-local сохранена отдельно.
