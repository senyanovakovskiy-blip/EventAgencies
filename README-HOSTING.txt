EVENTAGENCIES — ЗАКРЫТЫЙ ХОСТИНГ

Адрес: https://eventagencies-motion.racinggiant1.chatgpt.site
Админка: https://eventagencies-motion.racinggiant1.chatgpt.site/admin
Доступ: только владелец, через вход в свой аккаунт ChatGPT. Политика доступа
управляется Sites, а каждый API-запрос дополнительно требует identity владельца.
Данные заявок и истории изолированы по идентификатору вошедшего пользователя.

Облачная версия использует Cloudflare Worker + D1 через Sites.
Локальная версия продолжает использовать Node.js 24 и private-data SQLite.
Локальные обращения, файлы паролей и сессии не переносятся в облако.
Новая облачная база создаётся миграцией drizzle/0000_dear_hannibal_king.sql.
Сообщения клиентам и агентствам не отправляются.

Каталог, фотографии, анимации и формы сохранены из существующего браузерного
шаблона. Исходный React/TypeScript этого шаблона не восстанавливался.
Выбор агентств и незавершённый черновик остаются в браузере конкретного устройства.
Принятые заявки и работа с ними сохраняются на сервере и доступны владельцу
с другого устройства после входа в тот же аккаунт.

КОМАНДЫ
node --test tests/*.test.mjs — тесты локальной навигации и облачного API.
npm run build — подготовка статических страниц и сборка Worker для Sites.
npm start — локальная проверка собранного Worker (нужна локальная D1 миграция).
npm run start:local — исходный локальный Node-сервер с SQLite.
start.ps1 — исходный запуск локального сайта без установки зависимостей.

Локальная сборка находится в local-dist; сборка хостинга — в dist.
После перехода с предыдущей версии один раз перезапустите локальный Node-сервер,
чтобы он использовал новый каталог. start.ps1 или start:local пересоберёт страницы.

После изменений в облачной схеме создавайте новую миграцию через npm run db:generate.
Уже опубликованные SQL миграции не изменяются. Публикация выполняется через Sites
с упакованной сборкой dist и текущим отправленным коммитом source repository.
Основной GitHub origin сохранён; репозиторий Sites используется отдельно.

ПРОВЕРКИ ПЕРЕД ПЕРВОЙ ПУБЛИКАЦИЕЙ
14/14 unit/regression тестов прошли.
Полная сборка содержит 245 страниц.
